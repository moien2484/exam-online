## 🧠 About The Project

Welcome to **Exam Online** – a modern and user-friendly web app designed for taking multiple-choice exams.  
It includes exam flow, result calculation, and a clean UI for a smooth testing experience.

---

## 🚀 Features
- ✅ Multiple Choice Exams  
- ⏱️ Timer for each exam  
- 📊 Auto-calculated results  
- 🧭 Navigation between questions  
- 📱 Fully Responsive Design
